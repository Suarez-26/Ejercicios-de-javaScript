# 🧠 Ejercicios JavaScript

## 📌 Descripción

Repositorio educativo con ejercicios de lógica y programación en JavaScript. Cada archivo JavaScript resuelve un problema específico, útil para practicar habilidades básicas e intermedias.

---
## 📁 Estructura del Proyecto

├── index.html # Página base para ejecutar los scripts
└── js/ # Ejercicios individuales
  ├── Anagramas.js
  ├── Arcano.js
  ├── Comprometido.js
  ├── compatibles.js
  ├── envasadas.js
  ├── plagiadas.js
  └── temporal.js 

---

## ✨ Características por archivo

- **Anagramas.js**: Verifica si dos palabras son anagramas (mismas letras en diferente orden).
- **Arcano.js**: Decodifica símbolos especiales usando reglas similares a los números romanos.
- **Comprometido.js**: Detecta archivos comprometidos según la fecha de descarga y acceso.
- **compatibles.js**: Filtra candidatos que cumplen al menos el 70% de habilidades requeridas.
- **envasadas.js**: Verifica si una pila de frutas fue empacada correctamente (tipo LIFO).
- **plagiadas.js**: Detecta similitud entre dos textos comparando palabras comunes.
- **temporal.js**: Convierte segundos en formato de tiempo `hh:mm:ss`.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5** – para visualización básica en navegador  
- **JavaScript (ES6)** – para la lógica de los ejercicios  
- **Browser APIs** – como `prompt()` y `alert()` para entrada/salida básica
